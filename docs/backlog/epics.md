# Epic E1 — Renderer & chunks
Chunked WebGL2 renderer, greedy meshing, per-face AO, light + fog, 20+ chunks stable.
Spike: SPK-1.

# Epic E2 — Worldgen
Seeded noise, biomes, ores, caves, trees; infinite generation outward.
Spike: SPK-3 (sim budget).

# Epic E3 — Texture pipeline
Blender procedural textures (tools/tex), atlas packing, base64 embed via build, per-block tiles,
magenta missing-texture sentinel. Spike: SPK-2.

# Epic E4 — Player & interaction
AABB collision, 1.9 physics, break/place with drops, mining tiers, creative/survival.

# Epic E5 — Lighting & time
Sky/block light BFS, day/night, spawn-by-light.

# Epic E6 — Simulation systems
Tick loop budget, gravity blocks, fluids, redstone (later), TNT.

# Epic E7 — UI & inventory
Hotbar, GUI grids w/ drag-drop, crafting table + recipe book, furnace smelting, F3.

# Epic E8 — Mobs
Spawn rules, pathfinding (SPK-4), hostiles, passives + breeding, combat w/ cooldown.

# Epic E9 — Persistence
localStorage chunk/entity save (SPK-5), versioned schema.

# Epic E10 — Tier-2 content
Redstone suite, villagers/trading, nether/end, enchanting/brewing, rails, weather.
